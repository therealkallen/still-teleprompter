# Windows / Teams 手动验收

记录操作系统版本、显示缩放、Teams 版本、显卡/驱动、共享方式与录屏工具。未执行的条目不要标为通过。浏览器 UI 验证不能替代原生 Windows 测试。

## 核心桌面窗口

- [ ] 安装 NSIS 包、启动程序，首次打开示例稿件。
- [ ] 提词器始终位于 Teams、PowerPoint、浏览器之上。
- [ ] 拖动、缩放、最小化、任务栏恢复、关闭和再次打开。
- [ ] 重启后恢复窗口位置与尺寸；最小化退出不导致下次隐藏。
- [ ] 不同显示缩放、双显示器、断开第二显示器后窗口仍可找到。
- [ ] 第二次启动只显示已有实例。
- [ ] 从 Teams 输入框点击提词器滚动按钮/滚轮，继续输入到 Teams，确认没有抢焦点。
- [ ] PowerPoint 放映中用全局快捷键阅读，同时确认幻灯片不被意外切换。
- [ ] 打开编辑和设置时可以输入，按 Esc 或返回按钮回到阅读。
- [ ] 鼠标静止时隐藏工具栏；移动、悬停、键盘焦点时显示；隐藏不会造成正文跳动。

## 捕获状态和真实效果

- [ ] 初次启动默认开启；设置显示 API 已确认，不声称所有录屏都有效。
- [ ] 关闭后显示关闭；重启后保持关闭。
- [ ] 重新开启显示开启，持久化后重启验证。
- [ ] Windows 10 2004 之前的虚拟机显示不支持，不误报开启。
- [ ] 模拟 API 失败时显示失败/错误码，不误报开启。
- [ ] Teams **整屏共享**：另一设备检查 PowerPoint 前面的提词器是否被排除。
- [ ] Teams **应用窗口共享**：检查演示内容与叠放情况。
- [ ] 回看 Teams 会议录制，不仅查看本机共享预览。
- [ ] 深色、浅色、半透明预设分别测试共享和录制。
- [ ] 捕获中移动/缩放窗口，进入编辑和设置，自定义窗口边框处也无泄露。
- [ ] 关闭排除作对照，确认窗口可见；重新开启再次测试。
- [ ] 使用实际录屏软件测试显示器捕获、窗口捕获与不同捕获后端，分别记录结果。

## 内容与长稿

- [ ] 粘贴包含中文、英文、长段落、标题、提示、重复段落的稿件。
- [ ] DOCX 导入标题、段落、列表、粗体/斜体及 Presenter Cue 样式。
- [ ] TXT/Markdown 导入 UTF-8、UTF-16 BOM；不支持编码显示明确错误。
- [ ] 损坏 DOCX、空文件、超限文件给出可恢复错误。
- [ ] 源文件内容和修改时间保持不变。
- [ ] 修改文字、类型、层级，移动或删除段落；书签保持跟随 ID。
- [ ] 长稿（至少 200 个段落）滚轮及连续快捷键滚动平滑。
- [ ] 焦点在阅读窗口时，方向键、翻页键、空格、Home/End 正常。
- [ ] 切换稿件、关闭再打开，恢复各自位置；修改字号与行距仍保持当前位置。
- [ ] 章节跳转、前后章节、折叠子章节、全文搜索都可用。
- [ ] 当前位置书签、搜索结果书签、移除书签，重启后保持。
- [ ] 隐藏提示后跳转隐藏提示结果有合理回退，不导致卡死。

## 外观与快捷键

- [ ] 设置顶部可选择中文 / English，界面、提示和窗口标题即时切换，无需重启。
- [ ] 退出并重新打开仍使用所选语言；升级旧数据默认中文，原有讲稿、书签和阅读位置保留。
- [ ] 英文界面的编辑、导航、快速搜索、捕获状态和错误提示可用；讲稿内容保持原文。
- [ ] 340px 窄窗中英文标签不溢出；可以从 English 界面切回中文。
- [ ] 背景颜色/不透明度与文字颜色/不透明度独立。
- [ ] 设置页面在透明背景下依然可读。
- [ ] 所有字体、16–60px 字号、行距、提示颜色/斜体/隐藏正常。
- [ ] 340px 窄窗与较大窗口：无水平溢出，按钮和输入框可操作。
- [ ] 开启 Windows 减少动画时无滚动动画。
- [ ] 所有默认全局快捷键在其他应用具有焦点时正常，且不切换前台窗口。
- [ ] 编辑/设置/导航时快捷键不修改阅读位置。
- [ ] 普通输入和 Shift 单独组合不被注册；非法组合显示错误。
- [ ] 用其他程序占用一个组合键；该项显示冲突，其他项继续有效。
- [ ] 修改组合后旧组合不再响应；重启后新组合恢复。
- [ ] 不允许不同动作注册同一组合；关闭应用后释放组合键。

## 数据与备份

- [ ] 退出前保存成功；断网依然可用。
- [ ] 编辑页面显示自动保存说明；「保存到本机」成功后显示本机保存提示，底部状态准确。
- [ ] 退出并重新打开后可以直接使用编辑后的稿件；导航的「当前稿件」保留多份稿件。
- [ ] 阅读页放大镜 / Ctrl+F 打开搜索，不切换到导航页。
- [ ] 同一段重复匹配、中文、英文大小写、标点和跨粗体范围搜索正确；当前结果高亮并定位到眼线。
- [ ] Enter / Shift+Enter 与上下结果按钮可循环定位；无匹配状态清楚。
- [ ] Esc 收起搜索，不跳回搜索前的位置，恢复阅读控制与原生焦点模式。
- [ ] TXT 导出保留章节和提示标记；再次导入符合规则。
- [ ] JSON 备份包含段落强调、外观、书签和位置；导入添加新稿件副本。
- [ ] `.bak` 保留上一次数据；故意损坏主文件，显示错误并暂停保存，不覆盖原始文件。
- [ ] 文件系统拒绝写入时显示保存失败，可导出备份并重试。
- [ ] 原生关闭按钮/Alt+F4 等待保存成功；保存失败不会静默丢弃内容。
