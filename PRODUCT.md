# Still Teleprompter

<!-- impeccable:product-schema 1 -->

## Platform
web

Windows desktop utility, rendered with React in Tauri v2. The web preview cannot provide native window or capture features.

## Stack
Tauri v2, React, TypeScript and Rust, as specified in the supplied V1 requirements.

## Users
Presenters delivering long Microsoft Teams presentations while switching between PowerPoint, browsers and other applications.

## Product Purpose
Keep a manually controlled script visible, readable and easy to navigate without interrupting a presentation.

## Capabilities and Constraints
Local only. Paste, TXT, Markdown and DOCX import. Structured sections, spoken text and presenter cues. Bookmarks, search, persistent reading position, appearance and configurable global hotkeys. Windows capture exclusion is requested by default, with accurate API status and independent Teams testing required. No ASR, LLM, accounts or cloud.

## Brand Commitments
Apple-inspired minimalism, restrained typography, generous spacing, subtle rounded corners. No emojis or unnecessary decoration. Reading and editing/settings are separate surfaces.

## Evidence on Hand
Windows Desktop Teleprompter — V1.txt. No existing application or brand assets. Still is an implementation name, not a supplied brand.

## Product Principles
Reading is the primary surface. Manual actions always win. Preserve imported originals. State native failures clearly. Prioritize a runnable Windows application.
