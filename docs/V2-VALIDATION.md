# Still V2 beta 验证与待测项

日期：2026-10-13 至 2026-10-14（Asia/Singapore）。基线为 Still 1.0.2，当前版本为 2.0.0-beta.2。

## beta.2 定时模式（2026-10-14）

用户追加需求后，模式扩展为「手动 / 自动 / 定时」。定时设置 60–1200 字/分钟，默认 240，补充到旧 beta.1 设置，不改稿件、外观或语音设置。

- 56 项前端测试和 TypeScript 检查通过：新增实际字数统计、段落高度/字数双向换算、一分钟 240 字的时钟推进、暂停/手动重定位、缩放、末尾、空正文、长帧保护、设置迁移与边界、定时模式禁止启动 ASR。真实手动/定时控制器的组合测试验证快捷键继续时取消手动动画，仅保留一个滚动任务。
- 浏览器实际交互通过：输入 30 显示错误，60 可保存；定时滚动实际前进，手动按钮后变为 Paused 并保持 scrollTop=110，继续后向前到 118 而不回旧位置；最终到 End of script 后停止。
- 340×500 英文设置及运行/暂停/结束控件完整显示，无水平溢出；480×640 中文阅读通过。语速恢复为 240 后重载仍选择定时、尚未开始。截图是实际定时模式，不是模拟 ASR。
- 语速按正文文字/数字计数，英文每字母一字，标点/空白/标题/提示不计；按段落显示高度与间距换算平均速度，不宣称逐字追踪。窗口缩放时重新测量，手动操作、搜索、导航和页面隐藏暂停。
- 连续滚动定期记录位置，重启不自动开始；单动画任务，暂停/停止取消任务，长帧不补偿跳跃。
- 快捷键改为模式中性的「暂停 / 继续滚动」。在末尾再次点击开始，会显示向上定位后重新开始的提示；向上定位后保持当前视口并开始，已通过 hook 测试。

Windows release 构建及最终 ZIP 体积见本次构建输出和 release 中的 beta.2 size-report.json。原生窗口定时模式的长期运行与 Teams 演讲场景仍需按手动清单验证；此前语音验收边界继续适用。

## 实现范围

沿用 V1 的段落 ID、稿件、导航、搜索、书签、外观、Win32 捕获排除、无焦点阅读窗口和保存模块。新增本地 SenseVoice ASR、共享麦克风采集、有界音频缓存、独立对齐 Worker、保守恢复和自动滚动。数据 schema 继续使用 version 1；旧设置只补充 autoFollow 和暂停/恢复快捷键，不重建稿件。

Manual 和 Timed 不启动 ASR。Auto 在重启后仍需要点击开始。Auto 暂停保留麦克风识别，但不会对齐或滚动；停止及离开 Auto 会结束原生识别进程并关闭输入流。主动滚动、键盘滚动、搜索和导航暂停跟读，必须显式恢复。恢复会清除旧音频并拒绝旧识别和旧对齐结果。

## 已通过的自动和本机验证

- TypeScript 严格类型检查、前端生产构建和 43 项 V2 自动测试通过。原有 22 项测试保留；新增迁移、对齐、状态、滚动和异步竞争覆盖。
- Rust 编译、格式检查、原生缓存边界和全局快捷键验证。
- 真实麦克风的两秒共享输入检查：1 个输入设备，48,000 Hz，接收到 95,567 个单声道样本。仅在内存中检查，未保存、播放或上传。
- 真实 SenseVoice 原生推理与 Still 的二进制 PCM 管道协议验证。所有语言测试使用本地文件，既有中文测试样本与 Windows TTS 英文测试样本。
- 中文样本：模型加载 1,580 ms；3 个识别窗口，82–171 ms/窗口，均有识别结果。
- 合成英文样本：7 个窗口，93–180 ms/窗口；加载 2,250 ms；ASR 子进程采样峰值工作集 544.26 MiB。
- 交替语言测试样本：6 个窗口，96–178 ms/窗口；加载 2,328 ms；ASR 子进程采样峰值工作集 544.45 MiB。
- 480×640 中文阅读、340×500 英文阅读和英文设置通过浏览器布局检查，窗口无水平溢出。重载保留 Auto 和英文偏好，但状态为尚未开始。浏览器明确报告 ASR 需要 Windows 桌面版，不冒充识别成功。
- Windows x64 release 可执行文件构建通过；随包包含模型、词表、CPython、sherpa-onnx 原生扩展、ONNX Runtime 和对应许可。

本机推理耗时不等同于实际跟读延迟。首次等待音频至少 1 秒，默认窗口 3 秒、识别间隔 750 ms，正常对齐需要两个不同识别结果确认。完整进程的 CPU、内存和延迟需要真实演讲测量。

## 模型与运行库

- 从用户本机的 VoiceFlow ASR-only runtime 复制兼容资源；未修改 VoiceFlow，未下载模型权重。
- `model.int8.onnx`：239,233,841 字节，SenseVoiceSmall CTC、多语言；实际 protobuf 检查含 562 个 UINT8 权重初始化张量、917 个 FLOAT 张量，属于已验证兼容的动态 8 位量化格式。文件名为 int8，不代表所有张量均为有符号 INT8。包含 LFR/CMVN、语言及 ITN 元数据。
- SHA-256：`c71f0ce00bec95b07744e116345e33d8cbbe08cef896382cf907bf4b51a2cd51`。
- `tokens.txt`：315,894 字节。由既有 sherpa-onnx 加载并完成真实推理；检查脚本可再核实模型架构和张量类型。
- sherpa-onnx 1.12.28，ONNX Runtime 1.23.2，CPU provider，2 个推理线程，language=auto，use_itn=true。
- 不使用 Silero，当前用音量门限抑制静音窗口；不等待整句结束即可推理。音量门限不等同于完整 VAD。

## 已知边界与下一步

确定性匹配适合原文和小幅省略、插词。较大语义改写、非常短的语句和重复段落可能持续 Holding，需手动定位并恢复；不引入 Embedding、LLM 或云 API。

设备断开进入 Error。重新连接后在设置刷新、选择设备并再次开始，不会未经操作重新开启麦克风。部分设备的默认格式不受支持时会提示改选设备。设备列表采用枚举序号与名称，重新插拔后可能需要重选。

超大稿件的全局模糊搜索在 Worker 中执行，且只有一个在途任务和一个最新待处理结果；仍需测量最坏搜索耗时。当前没有保存音频、识别文字、稿件 telemetry 或 API key；诊断开关仅展示耗时、置信度及序号。

按 `V2-MANUAL-TESTING.md` 完成真实会议测试后再评估正式版本。Impeccable 本机引擎二进制缺失，context/detect 未能执行；界面通过截图检查与独立审阅验证，未把缺失的检测器标成成功。

独立界面审阅提出的两个问题均已修复并复审为 resolved：重选当前模式不会停止识别，暂停状态说明麦克风继续监听、停止才释放。复审的 ship 结论仅覆盖这两项修复；340px 暂停控件验证使用带明确标识的合成状态夹具，不是运行时真人跟读证据。
